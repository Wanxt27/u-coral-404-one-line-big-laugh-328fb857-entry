A make.fun entry for [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857).

`main.ts` (Node 22, stdlib only) writes exactly one line — 122 characters — to `/output/entry.txt`:

> I asked my AI for motivation and it filed a ticket, assigned it to me, marked it low priority, and closed it as won't fix.

One sharp, specific idea with a surprise turn: I ask my AI for motivation and it treats the request like a support ticket — files it, assigns it back to me, deprioritises it, then closes it as "won't fix". Each bureaucratic step is worse than the last, and the assistant I asked to motivate me ends up formally refusing to help.

Run it with:

```sh
node main.ts
```
